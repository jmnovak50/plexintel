# Predictive pipeline restoration

Restoration branch: `restoration/simple-predictive-pipeline`. Main and production remain at their existing references; no cutover is authorized by this document.

Reference: `764b2ee3920026d49ba1ad5b3705a9b25255f122`, immediately before `00a420c804cdde31d245a7b970c8a30c8b9de5a2`. Its ML scripts are unchanged from `7711b9f`, the preceding authenticated application release. The intervening commit added eligibility/lifecycle foundations, rather than changing prediction. This is the last pre-migration operational source reference, not evidence that its historical accuracy was valid. Its unrestricted watch profiles and random/preprocessed evaluation are deliberately not restored.

The replacement retains public library/history/feedback collection and the existing application scheduler, locks, execution logs, recommendation tables and APIs. `api/predictive` contains ordinary text preparation, corrected features, fitting, scoring and file loading. It has no store, generation activation, checkpoint journal, permanent staging populations or second lifecycle schema. Temporary tables disappear with the worker connection. The public active feature configuration points to an immutable checksum-addressed local model file; its pointer, vectors, training rows, recommendations and raw SHAP are published together in one PostgreSQL transaction. Fitting holds only the advisory writer lock, not publication-table locks. Source tables and the exact incumbent configuration are checked again within publication.

Canonical recovery, episode granularity, alias LOO, conservative uncertainty, audited Friends suppression, submission-time retrospective feedback and label maturity are extracted from reviewed implementation `232c940`. Semantic labels remain outside numeric features. Local Gemma 2 text inference has no fallback encoder, image request or automatic pull. Metadata is descriptive and rich; missing fields remain missing. Metadata and corrected event revisions are current snapshots, not proof of original historical application knowledge.

Classifier inputs are 768 target text coordinates, 768 canonical eligible-history mean coordinates, train-fold genre flags, top-20 director flags, decades and `watch_sim`. The profile uses each qualifying canonical title once (max watched/runtime > 0.5 or at least five events); prior watch vectors use the existing 0.5 qualification. Target aliases and future/unavailable events are removed from both. These are associative engagement inputs, not a measure of enjoyment or causal taste factors.

Labels and weights retain the reviewed policy: watch aggregate >=0.60 positive; meaningful partial <=0.35 negative only after 21 movie/14 episode days. Watch weight `min(1 + .5 * events, 5)`. Explicit interest positive/.75; rejection negative/5; watched-like positive/3; watched-dislike negative/5. Only one user/canonical outcome survives. Watched declarations without recorded viewing use creation time as observation cutoff and max(creation, modification) as label availability; actual first viewing is unknown. Post-watch declarations are auxiliary rather than additional first-exposure outcomes. Historical profiles are reconstructed at each cutoff; complete stored user profiles are used only for present-state interpretation.

The XGBoost architecture remains 100 trees, depth 6, learning rate .1, subsample .8, seed 42, two fitting threads, threshold .5 and training-fold negative class balancing. Vocabulary fitting and balancing use fit rows only. Chronological validation purges immature fit labels. Show-held-out validation removes held-out groups from profile dependencies. Gates remain chronological balanced accuracy >=.5, show-held-out balanced accuracy >=.5, and AP no more than .05 below the exact incumbent. A first cutover requires an explicit incumbent AP baseline bound to its model checksum. No incumbent means no AP regression comparator; this is identified rather than substituting a number.

Validation models and the final all-data fit are distinct. Only the former receive held-out performance claims. Reports include both classes, confusion matrices, Brier/ECE buckets, supervision segments, media/history segments and feature-group raw-margin SHAP. AP/NDCG can look strong under positive prevalence; labeled-candidate ranking is not catalog-wide accuracy. Small negative cohorts are flagged. A prospective test remains a separate requirement for independent generalization claims.

Implementation/qualification evidence and the reversible cutover procedure follow below as validation completes.
